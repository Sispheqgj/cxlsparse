# 最终五组实验结果

本目录保留 **2026-11-03 最后一轮完整交付复测**的精简结果。
原始 run ID 为 `kvpool-delivery-20261103T112349Z/formal`。
11 月 4 日的包目录整理及发布入口调整晚于这轮测量，不能把归档中的旧源码指纹
直接当作当前发布目录的指纹。再次运行脚本会生成当前代码的新快照和新结果。

## 配置与统计口径

单张 H100 PCIe 80GB、NSA-1B（16 层）、BF16、batch=1、hot=256。
History=4096/8192/16384 tokens，Extend=128/256 tokens。Extend 是候选后缀的 Query
位置数，不是候选商品数。各组使用相同输入、同一模型和 CUDA Graph；四组普通对照
均关闭跨 Query 去重，仅本方案开启。各组均保留热副本及按需取数。

每组每点两轮，每轮预热 3 次、测量 15 次；另有混合 Extend 复访序列。
共 30 个进程配置、2180 个请求，其中 steady 和 mixed 各 900 个计时请求。
下表为 steady 每点 30 个样本的 E2E 中位数，单位 ms，越低越好。

| History / Extend | RDMA 整批 | RDMA 注册复用 | CXL 整批 | TMA 不共享 | 本方案 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 4K / 128 | 42.892 | 39.829 | 19.605 | 19.888 | 14.403 |
| 4K / 256 | 61.239 | 57.994 | 25.813 | 27.799 | 16.618 |
| 8K / 128 | 48.964 | 46.281 | 23.145 | 23.142 | 17.343 |
| 8K / 256 | 69.401 | 64.399 | 30.099 | 31.487 | 19.023 |
| 16K / 128 | 58.360 | 54.403 | 30.850 | 30.755 | 25.304 |
| 16K / 256 | 82.049 | 77.009 | 38.633 | 40.496 | 28.245 |

六点几何平均 E2E 加速分别为：相对 RDMA 整批 3.019×、相对 RDMA 注册复用 2.828×、
相对 CXL 整批 1.397×、相对 TMA 不共享 1.439×。mixed 对应后面三组为
2.815×、1.408×、1.439×。Worker 与 E2E 是不同计时边界，完整数值见 CSV。

RDMA 使用本机 GPUDirect loopback，不是双机网络实验。软件计数读取载荷合计减少
87.82%，不等于测得的物理链路字节。TMA 不共享在 6 点中的 4 点 E2E 慢于 CXL 整批，
因此整体收益不能单独归因于异步搬运指令。

## 验收

- 48 组完整 hidden 输出比较完全一致。
- 2040 个非 prefill 请求通过执行路径和计数检查。
- 1224 组私有对照读取关系、408 组共享/私有请求对比通过。
- 18 次 DAX 区域恢复、12 次 RDMA Pool 会话释放通过。
